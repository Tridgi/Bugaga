# Bugaga - Telegram Bot

Простое приложение Telegram бота на Python.

## Описание

Это базовый Telegram бот, созданный с использованием библиотеки `python-telegram-bot`. Бот умеет:
- Отвечать на команды `/start`, `/help`, `/about`
- Повторять отправленные ему текстовые сообщения (эхо)

## Требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Tridgi/Bugaga.git
cd Bugaga
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

5. Получите токен бота:
   - Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
   - Отправьте команду `/newbot` и следуйте инструкциям
   - Скопируйте полученный токен

6. Добавьте токен в файл `.env`:
```
TELEGRAM_BOT_TOKEN=your_actual_bot_token_here
```

## Запуск

Запустите бота командой:
```bash
python bot.py
```

Бот будет работать до тех пор, пока вы не остановите его (Ctrl+C).

## Использование

После запуска бота, найдите его в Telegram по имени, которое вы указали при создании, и отправьте команду `/start`.

Доступные команды:
- `/start` - Начать работу с ботом
- `/help` - Показать список команд
- `/about` - Информация о боте

## Разработка

Для разработки и добавления новых функций редактируйте файл `bot.py`. Вы можете добавить:
- Новые команды (создайте функцию и добавьте CommandHandler)
- Обработчики других типов сообщений (фото, видео, документы и т.д.)
- Inline клавиатуры для интерактивного взаимодействия
- Подключение к базе данных для хранения данных
